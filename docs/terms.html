Приложение предоставляет информацию об интересных местах рядом с пользователем (музеи, парки, памятники и т. п.) из публичных открытых источников, включая Wikipedia, OpenStreetMap и другие сервисы. Приложение является бесплатным и не содержит рекламы.

4. Использование внешних навигационных приложений

По кнопке «Маршрут» приложение может передавать координаты выбранного места во внешние навигационные приложения (Яндекс Карты, Google Maps, Amap, Baidu Maps). Использование таких приложений регулируется их собственными условиями. Для работы отдельных сервисов (Google Places, Amap) вы можете указать собственные ключи API; приложение не несёт ответственности за использование этих ключей.
